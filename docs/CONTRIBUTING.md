# Contributing

## Current project stage

This project is in **v1 pilot** stage.
Contributions and feedback are welcome, but changes should favor:
- clarity
- determinism
- honest uncertainty reporting
- small, testable increments

## Preferred contribution style

Please prefer:
- focused changes
- one pattern or one report improvement at a time
- reproducible examples
- explicit supported/unsupported semantics

## Before proposing a feature

Please check:
- does it solve a real frequent case?
- does it fit current v1 scope?
- does it improve report usefulness?
- does it preserve best-effort honesty?

## Feedback format

Use `docs/FEEDBACK_TEMPLATE.md`.
