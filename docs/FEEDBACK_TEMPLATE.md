# Feedback Template

When reporting an unsupported or incorrect case, please include:

## 1. Short description
What did you expect and what did the tool produce?

## 2. Service method
Paste the smallest reproducible method.

## 3. Related callee methods
Include called methods if interproc is involved.

## 4. Fetch plan
Paste the relevant fetch plan or describe it.

## 5. Actual output
Paste:
- raw output
- normalized output
- comparison report

## 6. Expected useful result
What paths or report sections did you expect to see?

## 7. Importance
Mark as:
- frequent
- occasional
- edge case

## 8. Pattern category
Examples:
- foreach
- stream
- interproc
- bean by interface
- bean collection
- cast
- alias
- unknown break
